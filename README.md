# University App UI 🎓

A modern university discovery platform UI built using Next.js, TypeScript and Tailwind CSS.

## 🚀 Features

- University listing
- Dynamic university pages
- Course details
- Apply university interface
- Compare universities
- Search functionality
- Responsive design
- Smooth animations

## 🛠 Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- React Icons
